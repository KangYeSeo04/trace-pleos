## 만드는 법

```sh
python3 -I tools/geo/build_regions.py   # 받기(캐시: tools/geo/.cache) → 합치기 → 단순화 → assets JSON 2개
python3 tools/geo/check_regions.py      # 확인 표 + tools/geo/preview/regions_preview.png (Pillow 필요)
```

표준 라이브러리만 쓴다. 원본을 바꿀 때는 `SRC_VERSION`·`SRC_COMMIT`·`SRC_SHA256`을 함께 고친다.

## 단위 규칙

- **161 지역**(화면·방문 개수): 디자인 `PROV` 규칙. 특별시·광역시·특별자치시는 1곳, 옛 광주광역시 5개 구는 "광주" 1곳(코드 `12200`, 앱 전용),
  도의 시는 일반구를 합쳐 1곳(예: 수원시 `41110`), 군은 그대로. 개수는 코드에 쓰지 않고 데이터에서 센다.
- **시·군·구 256**(판정): 법정 시·군·구 코드(일반구 포함). 각 단위에 `region`(161 지역 코드)과 `sidoShort`·`name`이 있어
  "서울 중랑구" 같은 표시가 가능하다.
- 채색 묶음 10개: 서울 / 경기(+인천) / 강원 / 충북 / 충남(+대전·세종) / 전북 / 전남광주(+광주) / 경북(+대구) / 경남(+부산·울산) / 제주.
  지도 라벨은 "전남광주", 카드의 시·도 이름은 `sido`("전남광주통합특별시").

## 파일 형식

| 파일 | 크기 | 내용 |
| --- | --- | --- |
| `assets/regions_display.json` | 347 KB | viewBox 563.3×612(디자인 지도 칸). 지역별 `code·name·sido·group·inset·center·d`(SVG path, `PathParser`용). 섬 박스 `insets`(틀·라벨 자리). fill rule **evenOdd** |
| `assets/regions_lookup.json` | 2.2 MB | 위경도. `regions`(161, 중심점·소속 단위), `units`(256, `bbox`·`center`·`rings` 평평한 [lon,lat,…] 배열). 허용 오차 15 m. fill rule **evenOdd** |

- 이웃 지역은 경계를 공유하는 '호' 단위로 한 번만 단순화해 틈·겹침이 없다.
- 섬 박스: 울릉도·독도와 제주는 디자인 자리에 따로 배율을 키워 놓는다(`meta.scale`). 독도는 디자인 원 두 개 자리에 맞춰 크게 과장.
- 먼 섬 박스(본토와 같은 배율, 위치만 옮김): **백령도** = 옹진군 백령면·대청면(백령도·대청도·소청도),
  **흑산도** = 신안군 흑산면(흑산도·홍도·대둔도·다물도·영산도·태도·만재도·가거도).
  백령도만 빼면 본토 세로가 519px라 디자인(550px)에 못 미쳐 흑산면도 뺐다. 지금 본토는 x 50~435, y 15~565.
- 제주 박스는 본토와 겹치지 않아 추자도를 실제 거리대로 둔다(겹치면 스크립트가 추자도를 박스 위쪽으로 당긴다).
- 스크립트가 박스·라벨이 본토, 다른 박스, 지도 UI(제목·원래 크기 버튼·안내 문구, `meta.uiRects`)와 겹치는지 검사하고, 겹치면 실패한다.
- 판정용 지역 중심점(`regions[].center`)은 화면 배치와 무관하게 위경도 경계에서 구한다.
- 판정에서 어느 다각형에도 안 들어가는 점(해안·다리·바다 위 GPS)은 가장 가까운 단위로 붙이는 처리를 G-01에서 한다.
